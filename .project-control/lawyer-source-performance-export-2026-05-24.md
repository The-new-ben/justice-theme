# Lawyer Source Performance Export - 2026-05-24

## Purpose

Make the Lawyer Onboarding source performance board operational outside wp-admin. The owner can export source buckets, sort them by expected MRR, and work the highest-value outreach/payment follow-up lists.

## Research Basis

- Clio Grow's lead source revenue report summarizes business generated by advertising/outreach sources, including intake counts, hired matters, estimated value and revenue.
- Lawmatics positions custom reporting around identifying the highest quality leads, how they found the firm and how to convert them into paying clients.

Sources:
- https://help.clio.com/hc/en-us/articles/29739406189339-Clio-Grow-Reports
- https://www.lawmatics.com/custom-reporting/

## What Changed

- Added `Export source performance CSV` to the owner-only Source performance board in Lawyer Onboarding.
- Added a nonce-protected admin export action: `justice_export_lawyer_source_performance`.
- Export rows include:
  - source key, label and value
  - registrations
  - expected monthly and annual value
  - manual invoice count
  - invoice requested, invoice sent, payment confirmed, blocked and cancelled counts
  - city, practice and message variants
  - latest submission time
  - filtered admin URL for the source bucket
  - recommended next action

The owner can now export source performance, sort by expected MRR, and decide whether to repeat, pause, or manually chase a source bucket. This is especially useful before recurring Grow payments are approved because manual invoice follow-up is still the active money path.
