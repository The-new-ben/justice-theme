## SMART TITLE RULES FOR SUPPORTING ARTICLES

Every Criminal Law supporting article must pass this test:
- Can a user confuse this article's intent with "I want to find/hire a criminal lawyer"?
- If YES → rewrite the title to focus on the SPECIFIC subtopic.
- If NO → keep.

### Title Rewriting Rules

**FORBIDDEN patterns (cannibalizes pillar):**
- "עורך דין פלילי מומלץ" — ranking language, compliance risk, cannibalizes
- "עורך דין פלילי טוב / מוביל / מוצלח" — same
- "משרד עורכי דין פלילי מוביל" — same
- "כיצד לבחור עורך דין פלילי" — overlaps with pillar's own section

**ALLOWED patterns (distinct subtopics):**
- "כמה עולה ייצוג בתיק פלילי — מה להביא בחשבון" → price intent, distinct
- "חקירה במשטרה — זכויות נחקר ומה לדעת לפני כניסה לחדר" → procedural, distinct
- "מעצר ימים — מה קורה ואיך מגישים בקשת שחרור" → procedural, distinct
- "כתב אישום — מה הוא כולל ומה קורה אחרי הגשה" → procedural, distinct
- "מחיקת רישום פלילי — מתי אפשרי ואיך מגישים בקשה" → outcome, distinct
- "שימוע לפני כתב אישום — הכנה וטיעון" → procedural, distinct
- "הסדר מותנה — מתי מוצע ומה הוא כולל" → procedural, distinct
- "עבירות סמים — זכויות חשוד וחקירה" → offense-type, distinct
- "עבירות אלימות — מה קורה בחקירה" → offense-type, distinct
- "עבירות צווארון לבן — מה מיוחד בחקירה הכלכלית" → offense-type, distinct
- "ייצוג קטין בהליך פלילי — מה ההורים צריכים לדעת" → audience-specific, distinct
