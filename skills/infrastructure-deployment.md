```powershell

git push origin main 2>&1
```

Commit types: `FIX:`, `FEAT:`, `CONTENT:`, `REFACTOR:`, `DOCS:`

## REST API Patterns

### Authentication
```powershell
$creds = Get-Content "justice-theme\tools\gsc\wp-app-password.json" | ConvertFrom-Json
$b64 = [Convert]::ToBase64String([System.Text.Encoding]::UTF8.GetBytes("benbatash:$($creds.app_password)"))
$h = @{ "Authorization" = "Basic $b64"; "Content-Type" = "application/json" }
```

### Create Article
```powershell
$body = @{ title="..."; content="..."; status="publish"; slug="..."; "practice-areas"=@(170) } | ConvertTo-Json -Depth 5
$r = Invoke-RestMethod -Uri "https://jus-tice.co.il/wp-json/wp/v2/articles" -Method POST -Headers $h -Body ([System.Text.Encoding]::UTF8.GetBytes($body)) -TimeoutSec 30
```

### Update Article
```powershell
Invoke-RestMethod -Uri "https://jus-tice.co.il/wp-json/wp/v2/articles/{ID}" -Method POST -Headers $h -Body $body
```

### Assign Taxonomy
```powershell
$body = @{ "practice-areas" = @(TERM_ID) } | ConvertTo-Json
Invoke-RestMethod -Uri "https://jus-tice.co.il/wp-json/wp/v2/justice_lawyer/{ID}" -Method POST -Headers $h -Body $body
```

### Trigger Custom Fix Endpoint
```powershell
Invoke-RestMethod -Uri "https://jus-tice.co.il/wp-json/justice/v1/fix-category-base" -Method POST -Headers $h
```

## Sitemap

### Correct Sitemap (GSC-compatible)
- URL: `https://jus-tice.co.il/sitemap_index.xml`
- Generated by: Rank Math SEO plugin
- Format: XML Sitemap Index with sub-sitemaps
- Referenced in: robots.txt

### Custom REST API Sitemap (fallback, NOT for GSC)
- URL: `https://jus-tice.co.il/wp-json/justice/v1/sitemap`
- Generated by: justice-theme/inc/sitemap.php
- Use for: manual inspection, debugging only
- GSC REJECTS wp-json endpoints

### robots.txt
- Auto-generated by WordPress + our filter in seo.php
- Must reference: `Sitemap: https://jus-tice.co.il/sitemap_index.xml`
- Our filter removes stale references to custom endpoints

## Known Issues & Workarounds

### uPress nginx blocks .xml files
- Symptom: Direct .xml URLs return HTML instead of XML
- Workaround: Rank Math handles its own rewrite rules, which bypass this
- Our custom sitemap uses REST API endpoint as fallback

### Server Cache (SeoEdge/SiteGround)
- Symptom: robots.txt or pages show stale content
- Fix: Clear cache in WP Admin → SG Optimizer → Purge
- Alternative: Use cache-busted query strings for verification

### Taxonomy URL Structure
- Practice-areas taxonomy uses BARE slugs: `/criminal-law/` (not `/practice-areas/criminal-law/`)
- `/practice-areas/{slug}/` → 301 redirect to `/{slug}/` (routing-guards.php)
- Category base set to `category` (was colliding with practice-areas)

### Permalink Flush
- After rewrite rule changes: Settings → Permalinks → Save
- Or: POST to `/wp-json/justice/v1/fix-category-base`
- uPress sometimes needs double-flush
