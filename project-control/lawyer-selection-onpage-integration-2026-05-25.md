# Lawyer Selection On-Page Integration - 2026-05-25

## Honesty Statement

The external SEO/Gemini research was used as direction for live template improvements, not dumped into the repository as raw content.

What was integrated:

- The protected master-content row for `/find-lawyer-how-to-find-good-attorney/` was treated as the canonical route for the lawyer-selection guide, so no competing URL was created.
- Competitor-inspired patterns from the existing lawyer-index research were applied to actual user paths: filtering by field and city, trust signals, profile verification, reviews only when verified, and a visible upgrade/claim route for professionals.
- Profile language was reduced from "mini-site" marketing copy to a cleaner professional-profile presentation, because the profile itself must sell the lawyer, not advertise other lawyers inside it.
- The directory now explains what to check before choosing a professional, while keeping the cards CMS-controlled and editable.
- Lawyer registration, lawyer plans, dashboard and onboarding copy were aligned to the same "professional profile" language so the account-opening path does not feel generic or inconsistent.

What was not done:

- No CMS content was published.
- No competitor photos, reviews, ratings, or personal facts were copied.
- No fake education, success metrics, addresses, phone numbers, or verification claims were added.
- No redirects, canonicals, noindex, sitemaps, taxonomies, or migration settings were changed.
