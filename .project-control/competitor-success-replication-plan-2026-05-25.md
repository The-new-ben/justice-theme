## Hebrew Family / Divorce SEO Rule

Owner correction accepted: in Hebrew search intent, `עורך דין גירושין` and `עורך דין לענייני משפחה` should be treated as overlapping commercial signals, not isolated silos.

Implementation rule:

1. One commercial family/divorce authority layer should carry both phrases naturally.
2. Use titles like `עורך דין גירושין ודיני משפחה` or `עורכי דין לענייני משפחה וגירושין`, depending on page intent.
3. Do not create competing standalone pillar pages that both try to rank for the same commercial query unless each has a clearly different intent.
4. Support pages such as `מזונות`, `משמורת`, `חלוקת רכוש`, `הסכם ממון`, `גישור גירושין` and local pages should internally reinforce the same commercial family/divorce hub.
5. Article pages should answer the legal question first, then hand off to the relevant family/divorce lawyer cards. Generic marketing before the answer should be reduced.

## Basic Lawyer Listing Rule

We can build basic unclaimed lawyer cards from public factual data, but they must be safe:

- Allowed: name, firm name, city, practice areas, public website/phone if sourced, source URL, "unclaimed public listing" status, update/remove request.
- Not allowed without permission: copied competitor review text, copied ratings, copied headshots, copied logos, fake testimonials, fake "recommended" labels, fake membership, fake paid status.
- Picture policy: no generic stock thumbnails. For unclaimed profiles use a clean initials/firm-name badge. Use real headshots only when uploaded by the lawyer, owner-provided, licensed, or clearly permitted.
- Outreach path: "We created a basic public card from public information. Claim it, add photo/reviews/articles, activate leads."
