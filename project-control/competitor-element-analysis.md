## Site 1: din.co.il

### Observed Elements

| Element | Description |
|---------|-------------|
| Logo | Blue + orange text "din.co.il" with magnifying glass icon in the "d" |
| Hero | Large office photo background, centered H1 "עורכי דין ומידע משפטי בישראל", 2-field search (practice area + city) |
| Menu | פלילי, נזקי גוף, דיני משפחה, דיני עבודה, תעבורה, מקרקעין — practice areas as primary nav |
| Lawyer Card Fields | Photo, Name, ★ Rating, # recommenders, Location, Forum Manager badge, Views count, Description, Zoom/SMS/Call/Consultation CTAs |
| Category Structure | Practice area as top-level nav → lawyer list per category |
| Trust Signals | Views count, star rating, recommender count, badges |
| CTA Strategy | Multiple contact methods per card (Zoom, SMS, call) — low friction |
| Monetization | Promoted lawyer placements, featured spots |
| Mobile | Responsive, hamburger menu, cards stack |

### What to Adapt
- Multi-contact CTA on lawyer cards (WhatsApp, phone, inquiry form)
- Practice areas as primary navigation (already done, but needs dropdown)
- City-based filtering in hero search
- View count per lawyer (adds social proof even at 0)
- Stars or numerical rating system (only show if real)

### What to Avoid
- Forum-heavy design that feels dated
- Overwhelming number of tabs/sub-sections in header

## Site 2: psakdin.co.il

### Observed Elements

| Element | Description |
|---------|-------------|
| Logo | Red "P" icon + "אתר המשפט הישראלי" — clean, authoritative |
| Hero | AI bot "הלפי" — innovative, conversational legal help |

| Trust Signals | AI legal bot = modernity, forms library = utility |
| CTA Strategy | "Contact" as primary action per card |
| Monetization | Premium directory listings, service marketplace |

### What to Adapt
- Magazine section for SEO content depth (already have articles CPT)
- Dedicated menu item for "מגזין" / "מאמרים"
- Legal forms as utility section (future roadmap)
- "פסקי דין" as a content type adds authority

### What to Avoid
- AI bot requires significant backend — out of scope now
- "Live" section requires real-time infrastructure

## Site 3: midrag.co.il

### Observed Elements

| Element | Description |
|---------|-------------|
| Logo | "מידרג" in white on purple background, "מדרגים מהשטח" tagline |
| Hero | Giant live counter: 2.9M+ reviews, 11.9K+ professionals, bold purple BG |
| Menu | Hamburger → sector categories |
| Lawyer Cards | Name, 0-10 Rating, sub-ratings: Reliability/Quality/Price/Service, dated reviews |
| Trust Model | 0-10 rating with sub-categories, dated real reviews |
| CTA Strategy | Reviews = organic traffic, professional claims profile |
| Monetization | Professionals pay to respond, upgrade profile |
| Mobile | Full-screen hero counter, mobile-first |

### What to Adapt
- Trust counter in hero (we have: 1,209 articles, 51 practice areas, 20 cities)
- Sub-category fields on lawyer cards (years experience, languages, city) instead of ratings
- Visual scale/number emphasis in hero

### What to Avoid
- Review system with fake or unverified lawyers is legally dangerous in Israel
- Do not claim ratings or verification unless real system is built

## Key Takeaways for Immediate Implementation

1. **Menu must show practice areas** — all 3 competitors use practice areas as primary nav
2. **Lawyer cards need more fields** — not just name, add firm, city, areas, WhatsApp CTA
3. **Hero needs a visual layer** — din.co.il uses a real office photo, we need equivalent
4. **Social proof numbers matter** — 1,209 articles is real, show it big
5. **Mobile first** — midrag shows importance of mobile-first number display
6. **"מגזין" branding** — psakdin shows content = authority, our 1,209 articles should be visible
