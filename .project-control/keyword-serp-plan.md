# Keyword and SERP Execution Plan
Date: 2026-05-09
Status: ACTIVE

## Method

For every major keyword:

1. Search the keyword.
2. Record top result titles and result types.
3. Identify whether Google prefers lawyer pages, guides, directories, Q&A, government/legal sources, or city pages.
4. Decide the one primary Jus-Tice URL for that intent.
5. Build the pillar page or supporting page.
6. Add lawyer cards, LegalTech tools, FAQs, trust blocks, and lead CTAs where appropriate.
7. Link supporting pages to the pillar.
8. Link pillar pages back to supporting pages and relevant lawyer profiles.
9. Track risks in `cannibalization-map.csv`.
