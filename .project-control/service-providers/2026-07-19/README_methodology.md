# אינדקס נותני שירותים למערכת המשפט בישראל

תאריך בדיקה: 2026-07-19.

הקבצים נבנו ממקורות פומביים בלבד. מספרי רישיון מולאו רק כאשר התקבלו מקובץ ממשלתי רשמי או כאשר התאמת השם הייתה חד-משמעית. שדות שלא ניתן היה לאמת הושארו ריקים. מספרי 072/077 במדריכים עסקיים עשויים להיות מספרי קישור.

הופעה ברשימה אינה המלצה, אינה מבטיחה זמינות לקבלת תיק, ואינה מחליפה בדיקת תוקף רישיון, ניגוד עניינים, ביטוח מקצועי וניסיון רלוונטי טרם התקשרות.

בקטגוריות הרישוי המרכזיות נעשה שימוש בפנקסים הרשמיים. בקטגוריות ללא פנקס ציבורי מלא נעשה שימוש בדפי ספקים, במדריכים עסקיים ובאיגודים מקצועיים, והפער צוין בשדה סטטוס האימות.
