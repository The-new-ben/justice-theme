# הקבלן רוצה שאחתום על הליקויים שנמצאו בבדק בית נפתרו/פתוחים. מה עלי לעשות?

<p><strong>כיצד לנהוג כאשר קבלן רוצה שתחתום על רשימת ליקויים מבדק בית</strong></p>
<p>במצב כזה, חשוב להקפיד כמה דברים:</p>
<p>בדוק את הליקויים: וודא שכל הליקויים שנמצאו באמת תוקנו או שעדיין פתוחים.</p>
<p>השוואה לדוקומנטציה: השווה את מציאות העבודה לרשימת הליקויים ולכל הסכמות שנחתמו.</p>
<p>ייעוץ משפטי: התייעץ עם עורך דין לפני חתימה, כדי לוודא שאין לך התחייבות על דברים שלא באמת נמצאו או נפתרו.</p>
<p>צילום ותיעוד: צלם תמונות של הליקויים שנפתרו וכן של אלו שעדיין פתוחים. הכינו דוקומנט כתוב שיכול לשמש כראיה בעתיד.</p>
<p>התערכות לאפשרויות: דע מהן האופציות שלך במידה והקבלן לא יתקן את הליקויים כפי שנדרש.</p>
<p>חתימה כשלט: חתום רק לאחר שכל הפרטים ברורים ונערכו התיעצויות משפטיות.</p>
<p>זהירות והקפדה בתהליך זה יכולים לחסוך לך בעיות משפטיות וכספיות בעתיד.</p>

<h4><span>סוגי ליקויי בנייה:</span></h4>
<ol>
<li><strong><span>שלמות מבנית</span></strong><span> : סדקים בבסיס, ריצוף לא אחיד וצניחת אלמנטים מבניים.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : בדיקות סדירות על ידי מהנדסי מבנים.</span></li>
<li><strong><span>אבחון</span></strong><span> : טכניקות מתקדמות כמו סריקת רנטגן או קידוח ליבה.</span></li>
<li><strong><span>דיווח</span></strong><span> : דוח הנדסי מפורט.</span></li>
</ul>
<ol start="2">
<li><strong><span>חדירת מים</span></strong><span> : נזילות בקירוי, ניקוז לקוי, חלחול מים.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : כתמי מים, עובש או ריקבון.</span></li>
<li><strong><span>אבחנה</span></strong><span> : בדיקת לחות.</span></li>
<li><strong><span>דיווח</span></strong><span> : תיעוד מקרים עם תמונות וקבל הערכות קבלן.</span></li>
</ul>
<ol start="3">
<li><strong><span>בעיות חשמל</span></strong><span> : חיווט פגום, הארקה לא תקינה.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : אורות מהבהבים, שקעים שרופים או מכות חשמל.</span></li>
<li><strong><span>אבחון</span></strong><span> : בדיקת מעגל חשמלי.</span></li>
<li><strong><span>דיווח</span></strong><span> : הזמינו חשמלאי מורשה לדוח בדיקה.</span></li>
</ul>
<ol start="4">
<li><strong><span>פגמים מכניים</span></strong><span> : בעיות במערכות HVAC, אוורור לקוי.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : טמפרטורות משתנות, רעשים חריגים.</span></li>
<li><strong><span>אבחון</span></strong><span> : בדיקת רכיבים על ידי מהנדסי מכונות.</span></li>
<li><strong><span>דיווח</span></strong><span> : דוח מוסמך מהנדס מכונות.</span></li>
</ul>
<ol start="5">
<li><strong><span>אינסטלציה</span></strong><span> : צנרת דולפת, לחץ מים ירוד, בעיות ביוב.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : זרימת מים נמוכה, סימני מים.</span></li>
<li><strong><span>אבחון</span></strong><span> : בדיקות לחץ, בדיקות מצלמות.</span></li>
<li><strong><span>דיווח</span></strong><span> : דוחות בדיקת אינסטלציה מקצועיים.</span></li>
</ul>
<ol start="6">
<li><strong><span>חוסרים בחומרים</span></strong><span> : שימוש בחומרים לא תקינים או לא מספקים.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : הידרדרות לפני תוחלת החיים הצפויה.</span></li>
<li><strong><span>אבחון</span></strong><span> : בדיקות איכות החומר.</span></li>
<li><strong><span>דיווח</span></strong><span> : דוחות בדיקות מעבדה, יחד עם עדויות צילומיות.</span></li>
</ul>
<ol start="7">
<li><strong><span>בעיות תרמיות ובידוד</span></strong><span> : בידוד לא יעיל, גשרים תרמיים.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : טמפרטורות שונות בפנים.</span></li>
<li><strong><span>אבחנה</span></strong><span> : הדמיה תרמית.</span></li>
<li><strong><span>דיווח</span></strong><span> : דוחות ביקורת אנרגיה.</span></li>
</ul>
<ol start="8">
<li><strong><span>פגמי גימור</span></strong><span> : איכות ירודה של נגרות, צבע וחומרי גמר.</span></li>
</ol>
<ul>
<li><strong><span>זיהוי</span></strong><span> : בדיקה חזותית.</span></li>

</ul>
<ol start="9">

</ol>
<ul>

<li><strong><span>דיווח</span></strong><span> : דיווחים גיאולוגיים והידרולוגיים.</span></li>
</ul>
<h4><span>כיצד לדווח על ליקוי בניה:</span></h4>
<ol>
<li><strong><span>הערכה ראשונית</span></strong><span> : ערוך הערכה ראשונית כדי להבין את מהות והיקף הפגם.</span></li>
<li><strong><span>ייעוץ מומחה</span></strong><span> : שכור או התייעץ עם מומחה בנושא הרלוונטי לסוג הפגם.</span></li>
<li><strong><span>תיעוד</span></strong><span> : אסוף את כל הראיות כמו תמונות, דוחות קודמים או כל תקשורת עם הקבלנים או הבונים.</span></li>
<li><strong><span>דוחות מקצועיים</span></strong><span> : אבטח דו&#8221;ח מוסמך מהמומחים או המהנדסים.</span></li>
<li><strong><span>ייעוץ משפטי</span></strong><span> : התייעצו עם עורך דין מנוסה בדיני בנייה לתיקים מורכבים.</span></li>
<li><strong><span>צור קשר עם בנאי או קבלן</span></strong><span> : לבסוף, הצג את הממצאים שלך בפני הגורמים האחראים לפתרון, אשר עשוי לכלול תיקון, החלפה או פיצוי כספי.</span></li>
</ol>
