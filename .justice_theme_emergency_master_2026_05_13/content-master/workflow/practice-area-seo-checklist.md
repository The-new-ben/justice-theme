# Practice Area SEO Checklist
## Reusable for Every Legal Practice Area on jus-tice.co.il

### Before Starting a New Practice Area

- [ ] Previous practice area exit review is complete
- [ ] No high-traffic URL changes pending approval
- [ ] Homepage space balanced (not dominated by any single area)
- [ ] Menu structure accommodates the new area

---

### Layer 1: Data Verification
- [ ] Pull all existing WordPress posts/articles for this area
- [ ] Map current URLs with post IDs
- [ ] Pull GSC query/page data (12-month)
- [ ] Identify high-traffic protected URLs
- [ ] Count cannibalization groups
- [ ] Create master map CSV

### Layer 2: Competitor Playbook
- [ ] Identify top 10 SERP competitors for head keyword
- [ ] Document competitor page types and structure
- [ ] Extract content gaps (keywords they rank for, we don't)
- [ ] Extract sub-practice opportunities with volume/KD
- [ ] Create competitor patterns document

### Layer 3: Trust Cleanup
- [ ] Check toxic/spam anchors affecting this area
- [ ] Check for off-topic pages diluting authority
- [ ] Verify HTTPS canonical enforcement
- [ ] Check for duplicate titles/meta across the cluster

### Layer 4: Pillar Decision
- [ ] Select current safe pillar URL
- [ ] Document why (GSC data, content quality, age)
- [ ] Review category/taxonomy page
- [ ] Write/improve category intro text
- [ ] Verify pillar links to all spokes
- [ ] DO NOT change URL without owner approval

### Layer 5: Sub-Practice Mapping
- [ ] Map all sub-practice keywords with volume/KD
- [ ] Check existing coverage for each
- [ ] Assign business value and priority
- [ ] Create sub-practice map CSV
- [ ] Identify quick wins (KD < 15)

### Layer 6: Guide Content Mapping
- [ ] Map procedure/explainer keywords
- [ ] Check existing coverage
- [ ] Map required official sources
- [ ] Map internal link requirements
- [ ] Map CTA requirements
- [ ] Create guide content map CSV

### Layer 7: Anti-Cannibalization
- [ ] Build query-to-page map from GSC
- [ ] Find competing URLs per query
- [ ] Select canonical candidate
- [ ] Document merge candidates (don't execute)
- [ ] Protect high-traffic URLs

### Layer 8: Internal Linking
- [ ] Homepage links to pillar
- [ ] Category page links to pillar and top spokes
- [ ] Pillar links to all sub-practice and guide pages
- [ ] Every spoke links back to pillar
- [ ] Related spokes cross-link
- [ ] Anchors are natural Hebrew

### Layer 9: User / Googlebot / AI Bot Journeys
- [ ] User can find this area from homepage in 2 clicks
- [ ] Googlebot can crawl from homepage → pillar → all spokes
- [ ] AI engines can extract clear answers
- [ ] Breadcrumbs correct and match schema
- [ ] Sitemap includes all pages

### Layer 10: Technical SEO
- [ ] Title tags unique and descriptive
- [ ] Meta descriptions set
- [ ] One H1 per page
- [ ] Self-referencing canonical
- [ ] Article schema present
- [ ] FAQPage schema on FAQ sections
- [ ] BreadcrumbList schema correct
- [ ] Mobile layout correct

### Layer 11: E-E-A-T
- [ ] Author/reviewer on every page
- [ ] Legal disclaimer on every page
- [ ] Last updated date
- [ ] Official source links
- [ ] No fake reviews, ratings, or "best/recommended" language

### Layer 12: Business Alignment
- [ ] Lawyer profiles connected to practice area
- [ ] Lead form/CTA accessible
- [ ] Paid placement disclosure
- [ ] Future monetization space reserved

### Layer 13: Authority Plan
- [ ] Toxic backlink cleanup documented
- [ ] Directory listing targets identified
- [ ] Expert column targets identified
- [ ] City page opportunities mapped

### Layer 14: Exit Review
- [ ] All layers documented
- [ ] What is complete
- [ ] What is incomplete
- [ ] What is unsafe
- [ ] What needs owner approval
- [ ] Next 10 action items listed
- [ ] Ready for next practice area: YES / NO
