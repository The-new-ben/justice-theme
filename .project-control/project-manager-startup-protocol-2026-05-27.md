## Non-Negotiable Honesty Rules

- Do not claim revenue without private payment proof.
- Do not call static readiness a customer, supplier or paid lead.
- Do not present unpublished repo artifacts as public site progress.
- Do not hide tool blockers. If browser, uPress, Lovable, Gemini, Claude Code or payment-provider access is unavailable, state it.
- Do not use paid OpenAI, Anthropic, Gemini, Groq or other LLM APIs unless the owner explicitly approves new API spend.

- Do not create suppliers, invoices, payments, test charges, CRM records, live registrations or public CMS changes without explicit owner approval and a safe test scope.
