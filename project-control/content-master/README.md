# Content Master - System Architecture

This directory is the absolute source of truth for the Jus-Tice content restructuring and URL migration project.

**Golden Rule:** No content, URL, redirect, or structural change happens on the live website before it is fully mapped and approved in `content-master-inventory.csv` and `redirect-map.csv`.

## Core Files
- `content-master-inventory.csv`: The complete manifest of 1,199 WordPress posts combined with GSC performance data.
- `redirect-map.csv`: The 1-to-1 mapping of legacy Hebrew URLs to new English / Pillar URLs.
- `methodology.md`: The standard operating procedure for content clustering and migration.
- `work-log.md`: The ongoing ledger of actions taken by agents/users.
