# Skill: Jus-Tice Content Migration Workflow

## Purpose
Create safe, SEO-aware, cluster-by-cluster migration/update plans for Jus-Tice content.

## Required sequence
1. Read master file.
2. Validate missing data.
3. Validate cluster classification.
4. Choose small pilot.
5. Build pilot inventory.
6. Detect cannibalization.
7. Select pillar and supporting pages.
8. Map final English slugs.
9. Map one-hop redirects.
10. Build internal-link map.
11. Prepare owner approval packet.
12. Execute only after approval.

## Never do
- Never mass update all posts.
- Never redirect without final target.
- Never overwrite strong old content with weak new content.
- Never publish internal notes.
